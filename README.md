# 電車乗り換え検索

入力した利用日・時刻・出発／到着・経由駅を保持する乗換検索です。無料の検索リンクを基本にし、時刻・運賃のアプリ内表示は専用APIのダイヤ探索結果から作ります。

## 起動

Node.js 22以降を使います。追加パッケージのインストールは不要です。

```powershell
npm start
```

[http://127.0.0.1:8780](http://127.0.0.1:8780) をブラウザーで開いてください。Windowsでは `start.ps1` または `start.cmd` でも起動できます。終了は起動したターミナルで `Ctrl+C` を押します。

## 検索方法

- **Yahoo!乗換案内（無料）**：キー不要。条件を指定し「経路を検索」を押して、作成されたリンクを開きます。駅の候補・時刻・運賃は検索先で確認します。確認できた経由駅指定は1駅までです。おすすめは検索先の到着が早い順、標準の歩く速さは検索先の「少しゆっくり」に対応します。
- **アプリ内表示**：駅すぱあとAPIのダイヤ探索を利用できるキーが必要です。出発駅・経由駅・到着駅を駅コードに解決し、一括探索します。同名駅は候補から選びます。平均時刻・期限外ダイヤ・端点や経由駅が一致しない応答は採用しません。
- **時刻表**：公開ODPTに掲載された駅・方向・曜日ダイヤを表示します。利用日と内閣府の祝日一覧から曜日を設定し、選んだ時刻以降に絞ります。曜日別の通常ダイヤであり、臨時ダイヤ・運休は別途確認します。祝日一覧は2025〜2027年を収録し、対象外の年は曜日を選ぶ必要があります。深夜0時付近は前日の24時台の掲載も提供元で確認してください。
- **定期券**：乗換検索先で通勤／通学・定期券料金を確認します。アプリ内の定期券料金取得は未対応です。
- **運行情報**：ODPTから取得できた路線と更新時刻・期限を表示します。公開APIの対象は主に都営交通です。本文や状態の記載なしを平常運転とは扱いません。

段差の少ない経路、遅延回避、定期券区間、指定列車、特別なきっぷは、無料リンクでは検索先で設定・確認する必要があります。駅すぱあと接続では、これらの追加条件・交通機関除外・標準以外の歩行速度を選ぶと、対応するまで検索を停止します。条件を黙って削除して検索することはありません。

## APIとキー

API設定で入力したキーはローカルサーバーのメモリーで保持し、入力欄は空にします。ファイル・localStorageへ自動保存せず、サーバー終了または「キーを消去」で削除します。以前の版が保存したキーは自動再利用しません。「キーを消去」でブラウザーの旧保存も削除できます。

環境変数 `EKISPERT_API_KEY`、`ODPT_API_KEY`、`OPENAI_API_KEY` も利用できます。環境変数側の削除は設定した環境で行ってください。サーバーは127.0.0.1のみで待ち受け、API操作に同じOriginとセッショントークンを要求します。公開配信向けのユーザー認証サーバーではありません。

OpenAIは、利用者が明示的に押した参考検索だけに使います。既定は `gpt-6-luna`、選択肢は `gpt-6.1-sol`。Responses APIの `web_search`、`reasoning.effort=low`、`store=false` を使い、別モデルでの自動検証・自動再試行はありません。時刻・運賃の経路データには使いません。接続テストもボタン1回でAPIを1回呼び出すため、API料金が発生します。

## 保存・アラーム

お気に入り・検索履歴・旅費メモはブラウザーに保存します。ダイヤ経路の保存結果は、全条件と選択中の経路を一緒に保存し、取得から1時間以内だけ復元します。復元した結果には保存結果と明示します。

「5分前／5分後」は検索条件を5分ずらす操作です。前後の列車を1本単位で指定する機能ではありません。降車アラームは選んだ経路の到着日時から計算します。ブラウザーやPCの休止中は遅れて鳴る場合があります。旅費メモには実際の支払額を確認して入力してください。不明な運賃・別料金は0円に置き換えません。徒歩時間は目安です。

## 試験

```powershell
npm run check
npm test
npm run test:mutations
```

回帰試験27件：日本時間、日付またぎ、検索条件、ダイヤ応答、ODPT、検索中止、古い応答の破棄、画面状態、キャッシュ、キー処理、ローカルAPI制限を確認します。変異試験は6種の不具合を意図的に戻し、試験が検出できることを確認します。外部の有料APIは呼びません。

実ブラウザーで無料検索リンク、専用キー未設定時、公開ODPT運行情報、浅草駅時刻表、狭い画面を確認しました。駅すぱあとAPIは未契約のため、公式仕様に沿う模擬応答で確認しており、契約キーを使った実運用試験は未実施です。
